# Estudos da faculdade

Acervo de exercícios, provas e trabalhos desenvolvidos durante a faculdade, entre 2019 e 2022. Reúne registros dos estudos de programação, orientação a objetos, algoritmos e desenvolvimento web e mobile.

Cada projeto permanece em uma pasta própria, com seus arquivos e instruções originais. O código foi preservado como registro da época; a consolidação não atualiza dependências nem valida sua execução.
